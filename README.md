# Saturday 21 November 2026 — One Day of World News, One Picture

Entry for the make.fun bounty
[news-image-20261121](https://make.fun/bounty/news-image-20261121):
sum up 21 November 2026's world news in one image.

The poster is a broadsheet-style front page with **50 stories** from that
Saturday: 3 hero stories (the Kyiv bridges strike and the missile in Poland,
COP31 running into overtime, and Bitcoin's fall below $59,000), 10 numbered
cards, a dotted world map with pins at the real locations of the drawn
stories, 37 briefs, a UTC timeline, and a date-check box separating
Saturday's news from Friday's.

## Files

- `entry.png` — the poster, 1024×1024.
- `build_poster.py` — build-time renderer (Pillow): draws the page at
  2048×2048 and downscales it to `entry.png`. Deterministic.
- `main.py` — the entry program (Python 3, standard library only): copies
  `entry.png` into the output directory (`$MAKEFUN_OUTPUT_DIR` or `/output`).
